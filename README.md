# Saakshi Stays: Hotel Booking System (MERN)

A full-stack hotel booking website built with **MongoDB, Express, React and Node.js**.
*Saakshi Stays* is a fictional boutique hotel named after me, used for this project. Guests search rooms by date, see live availability and book; admins manage rooms and see every booking.

**Live demo:** https://saakshigadia.github.io/hotel-booking-system/
(The demo runs fully in the browser so it can be hosted free. Admin login: `admin@saakshistays.test` / `admin123`.)

## Features

**Guests**
- Search by check-in, check-out and number of guests, filter by room type
- Live availability per room type ("Only 2 left", "Sold out")
- Price summary before booking (nightly rate × nights)
- Sign up / log in with JWT authentication
- My bookings page with free cancellation until check-in day

**Admins**
- Dashboard with active bookings, booked revenue and total rooms
- See all bookings with guest details
- Add rooms and remove rooms (soft delete, so old bookings stay intact)

## How double-booking is prevented

Each room type has a `quantity` (e.g. 6 Garden Deluxe rooms). Two stays clash when one starts before
the other ends (`checkIn < otherCheckOut && otherCheckIn < checkOut`), so a guest can check in on the
day another checks out. Before saving a booking the API counts clashing confirmed bookings and rejects
it if the room type is full. It counts again right after saving and undoes the booking if two requests
grabbed the last room at the same moment.

## Project structure

```
server/
  src/models/        User, Room, Booking schemas
  src/routes/        auth, rooms, bookings
  src/middleware/    JWT auth, admin check, error handling
  src/utils/booking.js   date validation, overlap and price logic (pure functions)
  tests/             15 unit tests + 10 API tests
client/
  src/pages/         Home (search), RoomDetails, Login, MyBookings, Admin
  src/api/client.js  all API calls in one place
docs/                single-file demo build (generated by the Pages workflow)
```

## Run it locally

You need Node.js 18+ and MongoDB (local or a free MongoDB Atlas cluster).

```bash
# 1. API
cd server
cp .env.example .env          # set MONGO_URI and JWT_SECRET
npm install
npm run seed                  # sample rooms + admin account
npm run dev                   # http://localhost:5000

# 2. Website (new terminal)
cd client
npm install
npm run dev                   # http://localhost:5173
```

Tests: `cd server && npm test` (the first run downloads a temporary MongoDB, so it needs internet).

The GitHub Pages demo is built and deployed automatically on every push by `.github/workflows/pages.yml` (it runs `npm run build:demo`, which writes `docs/index.html`).

## API

| Method | Route | Who |
|---|---|---|
| POST | `/api/auth/register`, `/api/auth/login` | everyone |
| GET | `/api/auth/me` | logged in |
| GET | `/api/rooms?checkIn=&checkOut=&guests=&type=` | everyone |
| GET | `/api/rooms/:id` | everyone |
| POST / PUT / DELETE | `/api/rooms`, `/api/rooms/:id` | admin |
| POST | `/api/bookings` | logged in |
| GET | `/api/bookings/mine` | logged in |
| PATCH | `/api/bookings/:id/cancel` | owner or admin |
| GET | `/api/bookings` | admin |
